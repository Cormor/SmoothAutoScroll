# 支持开发共用资源

打开 [界面参考](index.html) 可离线查看支付宝和微信两张卡片。界面沿用 SimRacingOverlay 官方管理窗口的码面、标记、金额文案及标准扫码交互。应用从自身界面或相应宿主入口提供这项能力。支持完全自愿，由用户用对应付款应用扫码完成。

- 支付宝显示 ¥5.98，微信显示建议 ¥6。
- `assets/*-code.png` 是码面，深色主题的反色只作用于这一层。`assets/*-marks.png` 是透明标记层，保留原色。两层按原比例同尺寸对齐，四周预留 24 px 等效静区。暗色界面提供「标准扫码」以切回白底黑码。
- 图片随正式产物提供，按项目使用的固定版本收录。核对正式入口、主题和图片实际加载。修改码面、标记、静区或显示条件时，应以对应付款应用的实际识别核验，尤其是微信专用赞赏码。
- 授权资源源于 SimRacingOverlay 提交 `92aa10bff165ba89f7481654c143c99fb0757fcb` 的 `assets/support/` 和管理窗口支持页。共享目录仅保留面向使用者的四张图片层；更换收款资源时核对授权，不记录解码后的支付内容。
